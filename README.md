# JavaScript Todo List 📝

A responsive Todo List application built using HTML, CSS, and JavaScript. It allows users to manage daily tasks, track their progress, and save tasks locally using browser LocalStorage.

## ✨ Features

- Add new tasks.
- Delete individual tasks.
- Mark tasks as completed using checkboxes.
- Filter tasks by All, Pending, and Completed.
- Clear all completed tasks at once.
- Display total, pending, and completed task counts.
- Dark theme toggle.
- Save tasks and theme preference using LocalStorage.
- Add tasks using the Enter key.
- Responsive user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks!
